# 来源说明

熊猫录屏是熊猫 Jay 借助 Codex 开发的 macOS 录屏实践项目。

## 功能研究

早期对本地 Screen Studio 2.25.23 进行了静态功能研究，使用 REA 分析应用结构，并使用辅助脚本阅读字符串索引和相关逻辑。REA 的部分语义分析返回不完整结果，不能将全部研究结果归于自动恢复。

当前点击区间调度参考了研究到的规则：点击前 300 ms 至后 2500 ms，忽略结尾不足 1 秒的点击，末尾保留 800 ms，合并间隔不超过 2500 ms 的区间。当前镜头构图、五次缓动、0.7 秒入镜和 0.85 秒退镜为本项目后续体验调整；默认倍率为 1.75×。没有验证与 Screen Studio 逐帧等价。

本仓库不包含 Screen Studio 安装包、提取的源码文件或素材；MIT 许可仅适用于本项目有权授权的内容，不授予任何第三方软件或商标的权利。构建和运行无需安装 Screen Studio 或 REA。

## 验证范围

发布源码来自本地工作区提交 `7266846` 的应用代码。本机已验证内建屏全屏、DELL U2419H 全屏及区域录制、窗口录制、外接屏空闲插拔后的刷新，以及停止后显示处理进度与导出。音频和运镜曾分别用实录与合成素材验证。

这些结果仅代表开发机上的检查；不同硬件、旧系统、长时间录制以及录制中拔屏仍需进一步验证。仓库不分发包含私人桌面内容的验收素材。
