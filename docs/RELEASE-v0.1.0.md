# 熊猫录屏 v0.1.0 · 预览版

首个公开安装包，供尝鲜和反馈，尚非正式稳定版。

## 下载与安装

下载 `PandaRecorder-v0.1.0-macOS-arm64.zip`，解压后将「熊猫录屏.app」拖到「应用程序」。不要下载下方的 Source code 作为安装包。

- 芯片：Apple Silicon（M 系列），不支持 Intel。
- 最低系统：macOS 15；本轮构建环境为 macOS 26.5.2，旧系统仍待验证。
- 临时签名，**未经 Apple Developer ID 签名及公证**，首次运行可能被系统拦截。确认下载来源后，可在系统提供「仍要打开」时按提示操作；不建议关闭系统安全保护。
- 首次运行需要在「系统设置 → 隐私与安全性 → 录屏与系统录音」允许熊猫录屏，再退出重开。麦克风按需授权。
- 更换构建后如权限失效，请退出应用，移除旧授权条目，添加当前应用并重新开启权限。

## 功能

- 全屏、窗口和区域录制，支持在目标显示器上选择范围。
- 系统声音与麦克风独立开关。
- 可选自动运镜，支持 1.5×、1.75×、2×。
- 悬浮计时、停止、重录和取消，停止后自动显示主窗口。
- 原片与运镜成片预览，MP4 保存在本机。

## 已知限制与验证

区域不跨屏、不随窗口移动；窗口录制时请保持目标窗口位置和大小不变。无时间轴剪辑、摄像头或字幕功能。长时间音画同步、录制中拔屏及 macOS 15 尚未完成专项验证。

该版本沿用已在开发机验证的录制代码；本次检查了构建、arm64 架构、最低系统版本、本地签名完整性和 ZIP 完整性。未进行下载到另一台 Mac 后的完整安装验收。

视频默认保存在 `~/Movies/REA-MotionRecorder/`。请通过仓库 Issue 反馈，并去除截图和样片中的隐私信息。

## 校验

将 ZIP 和 `SHA256SUMS.txt` 放在同一目录，在该目录运行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```
